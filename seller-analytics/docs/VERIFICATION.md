# Проверка версии 0.1

10 октября 2026.

- 15 автоматических тестов прошли: округление денег, историческая стоимость, возврат в следующем периоде, запрет выдачи чистой прибыли при неполных данных, неизвестные статьи, нулевые знаменатели, CSV, повторная загрузка и корректировка, разделение режимов/кабинетов, HTTP API, некорректные даты, защита от запросов с чужого Origin/Host, CSRF, атомарность импорта, экспорт.
- JavaScript прошёл проверку синтаксиса Node.
- В браузере проверены обзор, поиск товара ACC-006, переключение на пустые реальные данные, формы расходов и стоимости.
- В журнале браузера при проверке не обнаружены ошибки или предупреждения.
- На ширинах 1440 и 390 CSS-пикселей ширина документа не превышает ширину окна. Внешний вид проверен на десктопе и в узкой панели. Это не полная проверка всех мобильных устройств.
- Снимок интерфейса сохранён отдельно как seller-analytics-preview.jpg.

Не проверены реальные WB/Ozon, налоги и сверка с TrueStats: доступы и первичные данные не предоставлены. API-тесты используют отдельную временную базу, рабочие данные не меняют.

Локальный сервер проверки останавливается после завершения работы. Повторный запуск — Start.command либо команда из README.
